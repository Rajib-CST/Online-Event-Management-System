# Online Event Management System

A web-based Event Management System built using **Java Servlets, JSP & JDBC** with **MySQL** database.

Users can browse events, book tickets, and manage bookings. Admin can manage events, users, and bookings from admin panel.

**Live Demo:** https://truth-trophy-arrive.ngrok-free.dev/OEM_updated/login.jsp
**Demo Video:** https://drive.google.com/file/d/101IUKCUB5Mek1ue4eul_2I0yVY9QdKf/view?usp=drivesdk

---

## ✨ Features

### For Users
- User Registration & Login
- Browse Upcoming Events
- View Event Details
- Book Events / Buy Tickets
- View My Bookings
- Cancel Booking

### For Admin
- Admin Login
- Add / Edit / Delete Events
- Manage Users
- Manage Bookings
- View All Events Dashboard

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JSP
- **Backend:** Java Servlets, JDBC
- **Database:** MySQL
- **Server:** Apache Tomcat
- **IDE:** Eclipse
